# concept-explainer

**Use when:** teaching an abstract concept (e.g. consistent hashing) — interactive visualization, comparison table, glossary.

**Data shape:** concept name, intuition paragraph, interactive demo spec (e.g. ring + add/remove buttons), comparison vs alternatives, glossary terms.

**Gotchas:**
- The interactive demo is the centerpiece — invest the JS budget there.
- Glossary terms should be hover-linked from inline mentions (not a footer dump).
- Comparison table needs a "best for" column; concept-vs-concept tables are useless without one.
