Daemon endpoints · what :63839 serves

Single Bun process. All routes resolve against the per-repo .html-kit/ dir or its pagefind index.

# method  path                                purpose
GET   /                                   # index page (this view)
GET   /p/<slug>/                          # project listing
GET   /p/<slug>/<file>.html              # single artifact, w/ injected head

POST  /api/annotate                       # body: {path, selector, note}
GET   /api/annotations/<path>             # list notes for one artifact
POST  /api/repos                          # register a repo by abs path

GET   /pagefind/*                         # static pagefind index + ui assets
GET   /search?q=...                        # json search proxy (cross-repo)
Annotation injection · what daemon adds to every <head>

When daemon serves an artifact, it streams the file and rewrites the head to wire in pagefind + the annotation strip. The original HTML stays self-contained on disk.

<head data-component="html-kit-injected">
  <!-- original head preserved above this line -->

  <link rel="stylesheet" href="/pagefind/pagefind-ui.css">
  <script src="/pagefind/pagefind-ui.js" defer></script>

  <script src="/_kit/annotation-strip.js" defer></script>
  <link rel="stylesheet" href="/_kit/annotation-strip.css">

  <meta name="html-kit:repo" content="example-startup-plans">
  <meta name="html-kit:path" content="05_smtp-config.html">
</head>
Register a new repo · bun run html-kit:register

From inside any repo, register it with the running daemon. The repo's .html-kit/ dir gets watched and indexed; new artifacts appear in the index within ~1s.

# 1. start the daemon once (any terminal)
bun run html-kit:daemon
› html-kit daemon listening on :63839

# 2. inside any repo with .html-kit/ artifacts
cd ~/code/example-startup-plans
bun run html-kit:register

# under the hood, POST /api/repos
curl -sX POST http://localhost:63839/api/repos \
  -H "content-type: application/json" \
  -d '{"path":"~/code/example-startup-plans","slug":"example-startup-plans"}'

# response
{ "ok": true, "slug": "example-startup-plans", "watched": 5 }
